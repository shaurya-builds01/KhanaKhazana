# KhanaKhazana
A beginner Django restaurant website built to learn and practice core Django fundamentals.

## 📌 About the Project
This is my first Django project. It was built primarily for learning and understanding how Django works.

## 🛠️ Concepts Practiced
- MVT Architecture
- Django Projects & Apps
- Virtual Environment
- URL Routing
- Views
- Django Template Language (DTL)
- Static Files
- Template Inheritance
- Include Tag
- Basic HTML & CSS

## 🚧 Project Status
This project is currently under development and is not fully functional yet.

## 🎯 Purpose
The main purpose of this project is to build a practical understanding of Django fundamentals while creating a simple restaurant website.
